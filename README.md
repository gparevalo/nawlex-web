# Solovisión Óptica

Web informativa en español para diagnóstico visual, lentes y salud visual empresarial en Quito y Cumbayá.

React 18 + TypeScript + Vite + Tailwind CSS 3. Se conserva el scaffold Express/Drizzle, los alias y los componentes UI de la base.

- `npm run dev`: desarrollo con Express.
- `npm run check`: TypeScript.
- `npm run build`: producción en `dist/`.
- `npm start`: servidor de producción.

Ver `docs/project-architecture.md` y `docs/visual-system.md`. Antes de publicar: confirmar dominio, teléfono público, logo original, fotos, direcciones y horarios. `VITE_SITE_URL` activa URLs canónicas; no se inventa un dominio.
